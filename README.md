# fluid

**fluid** is a living pixel-fluid audiovisual engine.

It is not just a visualizer. It is a system for creating, saving, mutating, crossing, and evolving visual organisms driven by sine waves, pixel motion, and sound.

> A pixelated fluid where the sine wave comes alive like a cobra.

## Core Vision

`fluid` turns visualizations into evolving entities.

Each visual can be stored as **visual DNA**, replayed later, mutated into new versions, crossed with another preset, and driven by live audio.
